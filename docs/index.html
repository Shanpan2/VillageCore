むらびと君 ヘルプ

VillageCore は、Discord サーバー運営と日常の遊びをまとめて支える多機能Botです。 ゲーム、音楽、チケット、役職パネル、出席管理、投票、AI応答、YouTube通知、ログ管理などを扱えます。

Botを招待 GitHubを見る
/help
/quick
/game
/music panel
/ticket setup

迷ったら /quick と /game から始めるのがおすすめです。

ゲーム

基本は /game から選びます。募集、参加、抜ける、開始、中止、ルール確認をパネルで操作できます。

ゲームパネル

/game でUNO、7並べ、大富豪、ポーカー、オセロ、五目並べ、詰将棋、将棋、Ito、コードネーム、人狼を選べます。

UNO

手札と操作はDM、公開チャンネルは進行メッセージを編集して場札を表示します。

7並べ

手札はDM画像で届きます。7を中心に同じマークのカードを順番につなげます。

大富豪

前の人より強いカードを出して、先に手札をなくした人が上がりです。

ポーカー

DMで届いた5枚の手札から交換し、役の強さで勝負します。コイン対応あり。

オセロ

対人戦とAI対戦に対応。盤面画像で進行し、勝者はユーザー名で表示されます。

五目並べ

対人戦とAI対戦に対応。先手、後手、ランダムを選び、先に5個並べると勝ちです。

詰将棋

初級、中級、上級から選択。正解すると難易度ごとにコインを獲得できます。

Ito / コードネーム / 人狼

会話系ゲームもパネル中心で進行できます。Itoは主催者がお題を決められます。

日常機能

サーバーで毎日使いやすい機能をまとめています。

クイック

/quick からゲーム作成、おみくじ、ダイス、じゃんけんなどをすぐ実行できます。

おみくじ

/omikuji で1日1回引けます。連続日数や一部結果で称号、バッジ、コインを獲得できます。

誕生日

登録済みの誕生日には通知と一緒に、年1回の誕生日コインボーナスが付与されます。

プロフィール

称号、バッジ、自己紹介、SNSなどを登録してプロフィール表示できます。

AI応答

Botへのメンションや返信でAIが応答します。利用制限時は時間を空けてください。

名言

メッセージを名言画像にしたり、登録済み名言を一覧表示できます。

検索

DuckDuckGoベースの検索機能で、Discord内から調べものができます。

Bot報告

/report でバグ、要望、不正利用、表示崩れなどをBot開発者へ送れます。

管理・運営

サーバー運営者向けの設定機能です。権限が必要な操作は管理者のみ実行できます。

チケット

問い合わせ用チャンネルを作成し、ログ保存、再オープン、削除ボタンに対応しています。

役職パネル

複数ロール付与や削除後の再追加に対応。既存パネルもできるだけ有効化されます。

出席管理

メンバーとポイントを保存し、再デプロイ後も継続できます。

ログ管理

削除ログ、VC入退室、BAN、キックなどの記録に対応できます。

音楽

YouTubeの仕様変更やCookie期限切れの影響を受けることがあります。

音楽が途切れる、403/429が出る、Cookieが無効と表示される場合は、Cookieの再設定、yt-dlp更新、時間を空けた再試行が必要になることがあります。

困った時

よくある原因を先に確認してください。

  • コマンドが出ない: Botの招待スコープに applications.commands があるか確認してください。
  • 権限不足: Botロールが対象ロールやチャンネルより上にあるか確認してください。
  • AIが返らない: Gemini APIの無料枠、429、503、モデル設定を確認してください。
  • YouTube通知が止まる: YouTube Data APIのクォータ上限に達している可能性があります。
  • ゲームが残っている: 管理者は /game_cancel_message や /game_cancel_all を使えます。
  • Botの不具合や要望: /report で種類を選んで送信してください。
